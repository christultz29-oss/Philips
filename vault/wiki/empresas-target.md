# Empresas Target — Panamá

Empresas objetivo para la búsqueda de empleo en logística / almacén / análisis de
inventario. Las vacantes concretas se rastrean en [[tracker-vacantes]].

## Criterios
- Operación logística real (WMS, centro de distribución, Zona Libre de Colón).
- Roles: analista de inventario, coordinador de almacén, supervisor logístico.
- Valoran SAP EWM/MM/TM ([[sap-ewm]]) o Power BI para reporting.
